# 한국 금융컨설팅 계약서 작성 스킬

## 작성 전 반드시 질문할 것
1. 계약 유형: (A) 고객 구독계약 (B) 협력업체 업무위탁/용역계약 (C) 비밀유지계약
2. 상대방: 개인(소비자)인지 법인인지 (소비자는 약관규제법·전자상거래법 보호 강화)
3. 구독 요금, 결제 주기, 자동갱신 여부, 해지·환불 기준
4. 제공 서비스 범위 (재무진단, 대출·자금조달 자문, 절세, 투자 관련 정보 등)

사용자가 "알아서 진행"이라고 하면 가정한 조건을 문서 앞머리에 [가정] 표시로 명시하고 진행한다.

## 공통 원칙
- 준거법: 대한민국 법. 관할: 법인 고객·협력사 계약은 회사 본점 소재지 관할 법원.
- 개인(소비자) 계약 관할 주의:
  - 온라인 가입·결제(통신판매) 계약은 전자상거래법 제36조에 따라 소비자 주소지 지방법원이 전속관할이므로 회사 본점 관할로 고정하지 않는다.
  - 대면 계약이라도 약관으로 고객에게 부당하게 불리한 관할 합의는 약관규제법 제14조로 무효가 될 수 있으므로 "민사소송법에 따른 관할 법원"으로 둔다.
- 문체: 「제1조(목적)」 형식의 조문 체계, 갑/을 대신 "회사"/"고객"(또는 "협력사") 사용.
- 빈칸은 `[ ]`로 표시해 사용자가 채울 수 있게 한다 (상호, 대표자, 주소, 사업자등록번호, 금액 등).
- 출력: docx 스킬로 Word 파일 생성 + 마지막에 "변호사 검토 필요 항목" 목록 첨부.

## (A) 고객 구독계약 필수 조항
- 서비스 범위와 **비보장 조항**: 수익·대출승인·절세효과를 보장하지 않음, 최종 의사결정은 고객 책임
- **규제 경계 조항**: 특정 금융투자상품의 개별 투자판단 자문 및 대출 중개·모집은 제공하지 않음(해당 등록·신고가 없는 경우)
- 요금·자동결제·자동갱신 사전 고지(갱신 전 통지), 중도해지 시 일할 환불 기준
- 개인정보 수집·이용 동의서 별첨(개인정보보호법), 신용정보 열람 시 별도 동의
- 비밀유지, 손해배상 상한(직전 12개월 수수료 총액 등), 계약 해지 사유
- 소비자 계약이면 고객에게 일방적으로 불리한 면책·위약금 조항 금지(약관규제법)

## (B) 협력업체 업무위탁계약 필수 조항
- 위탁 업무 범위, 산출물, 납기, 검수
- 대가·지급조건·세금계산서
- **고객 개인정보 처리위탁 조항**(개인정보보호법상 수탁자 의무, 재위탁 제한, 계약 종료 시 파기)
- 비밀유지, 지식재산권 귀속, 고객 직접 거래(우회영업) 금지 기간
- 협력사 과실로 인한 손해 배상·구상, 하도급 해당 시 하도급법 검토 표시
- 협력사가 세무사·법무사 등 자격사인 경우 해당 자격 업무는 협력사 명의·책임으로 수행함을 명시 (회사의 무자격 대리 소지 차단)

## (C) 비밀유지계약
- 비밀정보 정의·예외, 사용 목적 제한, 존속기간(종료 후 3년 등), 반환·파기, 위반 시 손해배상

## 마지막 단계
- 작성 후 "등록·신고 필요 여부 점검표"를 함께 출력: 투자자문업, 유사투자자문업, 대출성 상품 판매대리·중개업 해당 여부
- 문서 맨 끝에 "본 문서는 초안이며 서명 전 변호사 검토를 권장함" 문구를 넣는다.
